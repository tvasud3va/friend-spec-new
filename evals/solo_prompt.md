# Task: implement this project from its specification

The specification is in `spec/`. Read every file in it, in full. `spec/platforms/` describes the programs
to build (one per file): implement all of them, in the directories and with the build/launch setup those
files require. `server/server.py` is a working, hand-written server the programs talk to
(`python3 server/server.py --port 0` prints `LISTENING <port>`).

You have one session to deliver working programs. Build them, run them, and test them however you see fit
(you may write your own tests inside `clients/`). A hidden test suite will judge the result against the
spec. When you are done, finish with the structured result.
